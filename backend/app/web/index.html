    이미지 참고SDXL IP-Adapter / Klein 참고 편집

    SDXL은 IP-Adapter를, Klein은 생성 방식에서 참고 이미지 편집을 선택하세요. Klein은 아래 어댑터와 참고 강도를 사용하지 않습니다. 생성 결과 또는 직접 올린 한 장을 선택하세요. 대화 첨부와 자동으로 공유되지 않습니다.

    이 영역에 드래그하거나 이미지 선택 칸에서 붙여넣기 · 최대 12MiB

    스타일 · LoRA선택한 모델에 스타일 더하기
    LoRA · 최대 4개

    Checkpoint와 같은 계열의 일반 Linear·Conv2d LoRA를 지원합니다. Conv2d는 원본 커널 down + 1×1 up 형식입니다. SD 계열 UNet DoRA는 로더 검증 단계이며 학습 모델 이미지 품질은 별도입니다. 다른 계열 DoRA·LoHa·LoKr·mid 텐서·grouped/dilated Conv는 미지원입니다. 강도 0은 효과 없음, 1은 기본 강도입니다. 실제 대상 레이어/shape는 생성 전에 검사합니다.

    생성 임베딩 선택 안 함

    LoRA와 함께 학습된 토큰을 사용할 때 선택하세요. 아래 토큰을 복사해 원하는 프롬프트 위치에 붙여 넣으세요. 최대 4개 · SD1/SD2/SDXL

    보정 · 업스케일얼굴·손 보정과 해상도 확대
    자동 영역 보정 · 생성 후, 확대 전

    현재 체크포인트·VAE·LoRA로 검출 영역을 다시 그립니다. 강도가 높으면 얼굴이나 손 모양이 달라질 수 있습니다. 원본·보정본·마스크·영역별 전후 이미지를 따로 저장합니다.

    외부 VAE·업스케일러는 로컬 호환 프로필이 있는 파일을 선택할 수 있습니다. 최대 1024px 입력을 타일로 나눠 확대합니다. 생성 원본은 따로 보관합니다.

    고급 설정CLIP · 인코딩 · 모델 안내

    계열·슬롯 프로필이 있는 표준 CLIP safetensors만 선택합니다. 토크나이저는 해당 모델 구성을 유지하며 전체 가중치와 해시를 검사합니다. ANIMA·FP8/GGUF 인코더 교체는 미지원입니다.

    가중치 모드: (문구:1.3), (강조), [약화], 괄호 escape 지원. 최대600토큰, 유효 가중치0~4. ANIMA는 기본 모드를 사용하세요.

    ANIMA bundle/프로필 단일 파일 및 SD1·SD2·SDXL 구조 후보를 실행할 수 있습니다. SD1은 512~768px부터 설정하세요. SD2.1 768 모델은 v_prediction을 선택하세요. Prediction은 모델의 학습 설정에 맞춰 선택하세요. 프롬프트는 각 인코더의 토큰 길이 제한을 따르며 SD1/SD2/SDXL은 긴 프롬프트·가중치 모드를 선택할 수 있습니다.
